# Week 7 Assignment: My Notes & The Report Builder

- `my_notes.py` — Writes, appends, reads, and counts notes.
- `my_notes.txt` — Contains the four notes created by `my_notes.py`.
- `hubs.csv` — Contains learner names, hubs, and scores.
- `report_builder.py` — Reads learner data and creates a report.
- `report.txt` — Contains the generated learner report.
- `README.md` — Describes the assignment files and explains append mode.

Changing `"a"` to `"w"` would erase the existing notes before writing the new note. The file would then contain only the new note.
